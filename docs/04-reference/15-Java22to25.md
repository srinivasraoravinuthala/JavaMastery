## Java 22 (March 2024)

### JEP 456 — Unnamed Variables and Patterns (Final)

Replace meaningless variable names with `_`:

```java
// Enhanced for — variable not used
for (Order _ : orders) orderCount++;

// Catch — exception not used
try { parse(input); } catch (NumberFormatException _) {
    return OptionalInt.empty();
}

// Pattern — ignore component
if (response instanceof HttpResponse(200, var _, var body)) { use(body); }

// Lambda — parameter not used
list.forEach(_ -> processNextItem());

// Multiple underscores in same scope are allowed
for (int _ : list1) for (int _ : list2) pairCount++;
```

### JEP 454 — Foreign Function & Memory API (Final)

Stable API for calling native code and managing off-heap memory. Replaces JNI and `sun.misc.Unsafe`.

**Key types:**
| Type | Purpose |
|------|---------|
| `Arena` | Memory lifecycle owner (`ofConfined`, `ofShared`, `ofAuto`, `global`) |
| `MemorySegment` | Off-heap memory block |
| `MemoryLayout` | Describes C struct/array layout |
| `Linker` | Bridge to native functions |
| `MethodHandle` | Downcall (Java→Native) or upcall (Native→Java) |
| `SymbolLookup` | Locate native symbols |

```java
// Minimal example: call strlen
Linker linker = Linker.nativeLinker();
MethodHandle strlen = linker.downcallHandle(
    linker.defaultLookup().find("strlen").orElseThrow(),
    FunctionDescriptor.of(ValueLayout.JAVA_LONG, ValueLayout.ADDRESS)
);
try (Arena a = Arena.ofConfined()) {
    MemorySegment s = a.allocateFrom("hello");
    System.out.println((long) strlen.invoke(s));  // 5
}
```

**See also:** [`43-ForeignMemoryAPI.md`](../02-learn/43-ForeignMemoryAPI.md)

### JEP 455 — Primitive Types in Patterns (Preview)

Extend pattern matching to primitive types:
```java
// instanceof with primitives
long big = 100_000L;
if (big instanceof int i) {           // range-check + narrow
    System.out.println("fits in int: " + i);
}

// switch with primitive values
static String describe(double d) {
    return switch (d) {
        case double v when Double.isNaN(v) -> "NaN";
        case 0.0 -> "zero";
        case double v when v < 0 -> "negative";
        default -> "positive: " + d;
    };
}
```

Finalized in Java 25 as JEP 488.

### JEP 480 — Structured Concurrency (Preview)

Group related virtual threads as a unit — if one fails, others cancel:
```java
try (var scope = new StructuredTaskScope.ShutdownOnFailure()) {
    Supplier<String> user   = scope.fork(() -> fetchUser(id));
    Supplier<Integer> score = scope.fork(() -> fetchScore(id));
    scope.join().throwIfFailed();
    return new Profile(user.get(), score.get());
}
// On any failure: other fork is cancelled, scope exits cleanly
```
Finalized in Java 25 as JEP 505.

## Java 24 (March 2025)

### JEP 485 — Stream Gatherers (Final)

Custom stateful intermediate stream operations:

```java
import java.util.stream.Gatherers;

// Built-in gatherers
List.of(1,2,3,4,5).stream()
    .gather(Gatherers.windowFixed(2))      // [[1,2],[3,4],[5]]
    .toList();

List.of(1,2,3,4,5).stream()
    .gather(Gatherers.windowSliding(3))    // [[1,2,3],[2,3,4],[3,4,5]]
    .toList();

// Custom gatherer: running sum
Gatherer<Integer, ?, Integer> runningSum = Gatherer.of(
    () -> new int[]{0},                    // initializer
    (state, elem, downstream) -> {
        state[0] += elem;
        return downstream.push(state[0]);  // emit running sum
    }
);
List.of(1,2,3).stream().gather(runningSum).toList();  // [1, 3, 6]
```

### JEP 484 — Class-File API (Final)

Read and write Java `.class` files with the standard JDK:
```java
import java.lang.classfile.*;

// Read class
ClassModel cm = ClassFile.of().parse(Path.of("Hello.class"));
for (MethodModel method : cm.methods()) {
    System.out.println(method.methodName());
}

// Write class
byte[] bytes = ClassFile.of().build(ClassDesc.of("Hello"), cb -> {
    cb.withMethod("main", MethodTypeDesc.of(CD_void, CD_String.arrayType()),
        ACC_PUBLIC | ACC_STATIC, mb -> {
            mb.withCode(code -> {
                code.getstatic(CD_System, "out", CD_PrintStream)
                    .ldc("Hello, World!")
                    .invokevirtual(CD_PrintStream, "println", MTD_void_String)
                    .return_();
            });
        });
});
```

Replaces ASM, BCEL for JDK tooling. ASM/Byte Buddy still preferred for application-level bytecode manipulation.

### JEP 483 — Ahead-of-Time Class Loading & Linking

Cache the result of class loading and linking from a training run:
```bash
# Training run
java -XX:AOTMode=record -XX:AOTConfiguration=app.aotconf -jar app.jar

# Production run (faster startup using cached class state)
java -XX:AOTMode=on -XX:AOTConfiguration=app.aotconf -jar app.jar
```

Startup improvement: 10–40% for large Spring Boot apps.

## Java 25 LTS (September 2025)

### JEP 506 — Scoped Values (Final)

Immutable, thread-safe alternative to `ThreadLocal` for per-call data sharing:

```java
static final ScopedValue<String> CURRENT_USER = ScopedValue.newInstance();
static final ScopedValue<Locale> LOCALE = ScopedValue.newInstance();

// Bind and run
ScopedValue.where(CURRENT_USER, "alice")
           .where(LOCALE, Locale.FRENCH)
           .run(() -> handleRequest());

// In any method called within the scope
static void handleRequest() {
    String user = CURRENT_USER.get();    // "alice"
    Locale locale = LOCALE.get();        // FRENCH
}
```

**vs ThreadLocal:**
| | ThreadLocal | ScopedValue |
|-|-------------|-------------|
| Mutability | Mutable | Immutable |
| Scope | Thread lifetime | `where(...).run()` block |
| Memory | Leaked if not removed | Auto-freed on scope exit |
| Virtual threads | Inherited (copied) | Inherited read-only |
| Cost | Per-thread map lookup | Direct scope lookup |

### JEP 492 — Flexible Constructor Bodies (Final)

Statements allowed before `super()` / `this()` call:
```java
class BoundedList<E> extends ArrayList<E> {
    BoundedList(int capacity, Collection<? extends E> initial) {
        // Validation BEFORE super() — new in Java 25
        if (capacity <= 0) throw new IllegalArgumentException("capacity: " + capacity);
        var trimmed = initial.stream().limit(capacity).toList();
        super(trimmed);
    }
}

// Previously required static factory workaround:
// public static BoundedList<E> of(...) { validate(); return new BoundedList<>(...); }
```

**Restriction:** Cannot read or write `this` fields before `super()`.

### JEP 488 — Primitive Types in Patterns (Final)

All primitive types can be used in `instanceof`, switch patterns, and record deconstruction:
```java
switch (payload) {
    case byte b  -> handle((int) b);
    case short s -> handle((int) s);
    case int i   -> handle(i);
    case long l  -> handleLong(l);
    case float f -> handleFloat(f);
    case double d -> handleDouble(d);
    default      -> unknown();
}
```

## Migration Notes

### Java 21 → Java 22
- No breaking changes for standard code
- `FFM API` replaces `jdk.incubator.foreign` — update imports if using preview FFM

### Java 22 → Java 25
- String Templates (JEP 430) was **withdrawn** — don't use it (was preview in 21-22)
- `sun.misc.Unsafe` — several methods deprecated for removal; migrate to VarHandle or FFM
- Check for use of `finalize()` — scheduled for removal

### Enabling Preview Features
```bash
javac --enable-preview --release 25 MyApp.java
java  --enable-preview MyApp
```
Preview features are NOT recommended for production — APIs may change.
