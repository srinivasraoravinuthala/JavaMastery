## Interview stages

1. **Phone screen** — fundamentals + 1 easy/medium DSA
2. **DSA rounds** — approach, complexity, edge cases
3. **Low-level design** — class model + SOLID + patterns
4. **System design** — scalability, trade-offs (senior+)
5. **Behavioral** — STAR stories

## DSA framework

Clarify → Examples → Brute force → Optimize → Code → Test → Analyze complexity

## 30 / 60 / 90-day plan

| Period | Focus |
|--------|-------|
| Days 1–30 | Core Java, Collections, 30 easy DSA |
| Days 31–60 | Streams, JVM, Concurrency, 40 medium DSA |
| Days 61–90 | System design, 20 hard DSA, mocks, behavioral |
