## Java Engineering Levels

### Junior Java Developer (0–2 years)

**Expected skills:**
- Core Java (OOP, Collections, Exceptions, basic Generics)
- Basic Spring Boot — REST endpoints, JPA, application.yml
- SQL — basic CRUD, joins
- Git — commit, branch, PR
- JUnit 5 — basic unit tests

**Typical work:** Feature tickets, bug fixes, CRUD endpoints, documentation.

**Salary (US):** $70K–$110K · (India): ₹5–12 LPA · (UK): £35K–£50K

---

### Mid-level Java Developer (2–5 years)

**Expected skills (beyond junior):**
- Java 11–17 features (var, records, sealed, streams fluency)
- Spring Security, Spring Data JPA, Spring Cloud basics
- REST API design — versioning, pagination, error handling
- Docker basics — Dockerfile, docker-compose
- Testing — Mockito, integration tests with TestContainers
- CI/CD — GitHub Actions or Jenkins pipeline
- Basic concurrency — thread pools, CompletableFuture

**Typical work:** Design new features end-to-end, mentor juniors, write tech specs.

**Salary (US):** $110K–$160K · (India): ₹12–30 LPA · (UK): £50K–£75K

---

### Senior Java Developer (5–10 years)

**Expected skills (beyond mid):**
- Java 21 — virtual threads, pattern matching, records fluency
- Microservices architecture — service decomposition, API gateway, service mesh
- JVM internals — GC tuning, heap analysis, JFR profiling
- Advanced concurrency — Reactive, StructuredConcurrency, lock-free algorithms
- Cloud-native — Docker, Kubernetes, cloud provider (AWS/GCP/Azure)
- System design — CAP theorem, consistency models, distributed systems basics
- Security — OAuth2, JWT, OWASP Top 10

**Typical work:** Architecture decisions, cross-team tech leadership, performance investigations.

**Salary (US):** $155K–$220K · (India): ₹30–60 LPA · (UK): £70K–£110K

---

### Staff / Principal Java Engineer (10+ years)

**Expected skills (beyond senior):**
- Java 22–25 features in production
- Organization-wide technical strategy
- Platform engineering — internal libraries, frameworks, developer experience
- Cross-domain expertise (data, infra, product)
- Mentoring and growing senior engineers
- Public speaking, open-source contributions
- GraalVM/native image for cost reduction
- OpenTelemetry, SRE practices, SLOs

**Typical work:** Define tech direction, lead multi-quarter initiatives, represent team in executive discussions.

**Salary (US):** $220K–$350K+ · (India): ₹60–120 LPA · (UK): £100K–£160K

## Skills That Differentiate Senior+ Developers

1. **GraalVM Native Image** — most developers haven't used it; big differentiator for cloud-native cost optimization
2. **JVM Profiling** — actually know what GC is doing; can tune production systems
3. **Distributed Systems** — SAGA, CQRS, event sourcing, consistency vs availability trade-offs
4. **Java Virtual Threads + Reactive** — understand when to use each and why
5. **Security by Design** — threat modeling, not just "add Spring Security"
6. **Observability** — OTel, distributed tracing, SLOs (not just logging)

## Interview Preparation by Level

### Junior
- Core Java Q&A (this repo's `03-interview/01-CoreJava.md`)
- Two or three LeetCode easy problems
- Basic Spring CRUD demo project

### Mid-Level
- All core Java interview docs in this repo
- LeetCode medium (HashMap, two-pointer, sliding window)
- System design basics (URL shortener, rate limiter)

### Senior
- Deep JVM, concurrency, streams, design patterns
- LeetCode medium/hard — trees, graphs, DP
- Full system design interviews (chat, payment system, video streaming)
- Behavioral — STAR method for leadership/conflict stories

### Staff/Principal
- Architecture discussions — trade-offs, why not X
- Experience leading migrations (Java 8→17, monolith→microservices)
- Past impact — cost savings, reliability improvements, team growth
