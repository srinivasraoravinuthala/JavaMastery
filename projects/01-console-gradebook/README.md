# Project 01 — Console Gradebook

**Unlock after:** [Learn ch.09 User Input](../../docs/02-learn/09-UserInput.md)

## Goal

Build a console app that reads student names and scores, then prints average / highest / lowest.

## Done when

- [ ] Prompt for N students
- [ ] Store names + scores in arrays (or lists)
- [ ] Print average, max, min
- [ ] Reject invalid scores (e.g. outside 0–100)

## Run

```bash
java projects/01-console-gradebook/Gradebook.java
```

## Stretch

Add letter grades (A–F) and write results to a `.txt` file (after ch.28 I/O).
