# Project 02 — Library OOP

**Unlock after:** [Learn ch.15 Records & Sealed](../../docs/02-learn/15-RecordsAndSealed.md)

## Goal

Model a tiny library: `Book`, `Member`, checkout/return, and print overdue items.

## Done when

- [ ] Classes with encapsulation (private fields + getters)
- [ ] Checkout assigns a book to a member
- [ ] Return clears the assignment
- [ ] Demo `main` prints inventory state

## Run

```bash
java projects/02-library-oop/LibraryApp.java
```
